# Panel de capas

Contenedor de altura fija; el desplazamiento pertenece solo a la lista, manteniendo visibles las acciones.

Las seis acciones inferiores se distribuyen en dos filas centradas de tres botones. Cada botón conserva 48 × 48 dp de superficie táctil, con separación de 8 dp y márgenes en el contenedor. El ancho y la altura exterior del panel y las filas de capas mantienen su configuración.
